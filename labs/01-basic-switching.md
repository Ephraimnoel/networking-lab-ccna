# Lab 01 — Basic Switching

**Status: Planned**

## Objective

Build the initial topology and understand basic Layer 2 switching before adding VLAN segmentation.

## Scenario

Northstar Services needs a small switched network. Begin with a simple set of endpoints and switches so that physical/logical connections and basic forwarding can be observed.

## Prerequisites

- Cisco Packet Tracer installed
- Requirements and proposed addressing plan reviewed
- A saved blank project file

## Tasks to perform

1. Place the required switches and end devices.
2. Connect devices using appropriate simulated cables.
3. Assign temporary or documented test addressing as appropriate.
4. Observe link states and MAC learning.
5. Verify same-network communication.
6. Record any design decisions or issues.

## Commands/concepts to investigate

- `show mac address-table`
- `show interfaces status`
- `show interfaces`
- Collision domains, broadcast domains, MAC learning, access ports

## Expected outcome

You should be able to explain how the initial switch topology forwards frames. The actual result must be recorded after testing.

## Evidence to capture

- Topology screenshot
- Relevant switch verification output
- Test addresses and connectivity results
- Notes explaining what you observed

## Completion criteria

- Topology is saved.
- Basic switching behavior was personally tested.
- Evidence is stored or referenced.
- README/checklist status is updated honestly.
